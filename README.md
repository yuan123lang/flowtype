# FlowType

当前版本实现：

- 首页成长树：每通关一关增加叶子
- 闯关模式：按关卡推进（每关 8 词）
- 隐藏拼写：只显示长度下划线，不直接显示完整单词
- 打字音效：正确/错误/通关音效（可开关）
- 错题本：输错自动加入，支持集中复习
- 单词解析：每个单词拼写成功后展示意思、发音、用法、考试例句
- 发音优化：优先选择英文 voice，自动朗读单词两遍并跟读例句
- 我不会跳过：点击“我不会，跳过并加入错题”可直接进入下一个词
- 本地持久化：关卡、叶子、错题保存在 `localStorage`

## 使用

直接打开 `index.html`。

如果浏览器限制本地资源，使用：

```powershell
cd G:/Flowtype
python -m http.server 5173
```

访问 `http://localhost:5173`。
